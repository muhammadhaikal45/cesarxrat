📷 QR Pairing

Generate QR Code untuk menghubungkan device target ke akun Anda.

Token (berlaku 24 jam)
----

Cara Pakai:

  1. Generate QR Code di atas
  2. Screenshot / klik "Bagikan QR"
  3. Kirim ke HP target via WhatsApp, Telegram, dll
  4. Di HP target: buka aplikasi System Update → pilih QR dari galeri
  5. Device otomatis muncul di menu Device Target
